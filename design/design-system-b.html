design system · option b · v0.1

scenic route — a dusk minimal ui for the off-road cv

Instead of adding a second visual world on top of the game, this option borrows the game's own Art of Rally-style language: soft dusk colors, all-lowercase type, and quiet smoked-glass chrome that lets the 3D island stay the hero. Same custom icon set as Option A — still zero emoji — but the personality comes from typographic restraint rather than print texture.

01

the game is the poster

UI recedes: translucent panels, hairline strokes, no borders or hard shadows competing with the 3D scene.

02

lowercase, letterspaced

All chrome text is lowercase with generous tracking — the signature Art of Rally register, instantly un-generic.

03

one warm accent

Amber marks everything interactive or earned. Zone hues appear only as small dots and rings, never as fills.

04

icons, not emoji

The same monoline 24×24 sprite as Option A — consistent weight on every OS, tinted by context.

buttons

One solid amber pill for the primary action; everything else is a hairline ghost or a smoked round icon button. No gradients, no bevels.

chips & tags

Waypoint chips are hairline pills with a status dot: dim when undiscovered, amber when found. Skill tags are the same hairline language in sentence-height rows.
